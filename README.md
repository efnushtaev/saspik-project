# САСПИК Проект — обзор

**САСПИК (Сеть Автоматизированных Систем для Производства и Контроля)**
Программно-аппаратная платформа для организации совместного производства, построенная на принципах децентрализации и модульности. Система позволяет гибко объединять оборудование, управлять производственными процессами и обмениваться данными между участниками в реальном времени.

### Иерархия системы
#### Кластер

Базовый автономный элемент распределённой сети САСПИК.

Может быть развёрнут как в удалённом облаке, так и на локальном сервере предприятия.

Каждый кластер независим, но при необходимости может взаимодействовать с другими кластерами через защищённые каналы.

#### Юнит

Составная часть кластера, выделяемая по функциональному назначению (например, «теплица», «цех», «склад», «логистический хаб»).

В рамках одного кластера может быть развёрнуто произвольное количество юнитов разного типа.

Объединение юнитов в кластер и их конфигурация выполняются пользователем через центральную панель управления платформы.

#### Объект

Элемент юнита, представляющий собой отдельное физическое или виртуальное устройство (датчик, контроллер, станок, камера, шлюз и т.д.).

Объекты подключаются к платформе для управления, мониторинга и обмена данными между собой.

Один и тот же объект может быть частью любого юнита (гибкая привязка), что позволяет перенастраивать логику работы без физического переподключения.

### Ключевые особенности
Децентрализация – отсутствие единой точки отказа; каждый кластер работает автономно.

Масштабируемость – добавление новых кластеров, юнитов и объектов не требует остановки системы.

Гибкость – пользователь сам определяет структуру и связи между элементами.

Безопасность – все обмены данных шифруются, разграничение доступа на уровне юнитов и объектов.

Кроссплатформенность – поддержка облачных и локальных развёртываний.

## Структура системы

### Аппаратная часть
- **Статичная** — теплицы, магистрали, конструкции
- **Крупноузловая** — насосы, приводы, пневматика, двигатели
- **Силовая** — питание, генераторы, преобразователи
- **Мониторинг** — IoT-датчики (температура, влажность, уровень воды)
- **Автоматика** — реле, контроллеры, шлюзы
- **Роботы** — мехатронные платформы с ROS2

### Программная часть
- **Кластер** — микросервисное ядро (Node.js, Express, Inversify, MongoDB)
- **MQTT брокер** — собственный брокер с движком сценариев (RulesEngine)
- **UI** — адаптивное SPA для управления юнитами и объектами
- **IoT-прошивки** — ESP32 (ESP-NOW, MQTT, deep sleep)
- **CV модуль** — компьютерное зрение (планируется)
- **Роботы** — ROS2-ноды (планируется)

## Пилот

**Статус:** Запущен. Теплица установлена, кластер развёрнут.

Первый пилот — автоматизированная компактная теплица с мониторингом и удалённым контролем микроклимата:
- ESP32 шлюз + ESP-NOW сенсорные узлы
- Управление реле (свет, насос, увлажнитель, вытяжка)
- Кластер на VDS (Portainer, Docker)
- Приложение-кабинет для мониторинга (atsap-social.ru)

### Текущие направления
1. UI — нормальный интерфейс с любого устройства
2. MQTT брокер — собственный, с движком сценариев
3. Роботизация — ROS2, мехатроника
