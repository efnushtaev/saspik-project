# ⧫ Документация на плату узла meshrover

#### ESP32-S3-DevKitC-1 в розетке + DWM3000, 80 × 55 мм, один слой

Плата-носитель для стенда Stage 1: готовый модуль ESP32-S3-DevKitC-1 вставляется в розетку 2×22,
рядом стоит DWM3000 с вынесенной вправо антенной. Питание — 5 В на клеммник; ESP32 питается от своего
стабилизатора на DevKit через вывод 5V, DWM3000 — от отдельного LDO 3,3 В на плате.

### Состав

| Файл | Что это |
| :--- | :--- |
| `esp32s3-dwm3000-board.py` | генератор чертежа — единственный источник истины по оформлению |
| `board.yaml` | данные платы: габарит, цепи, розетка, DWM3000, перечень элементов |
| `esp32s3-dwm3000-board.dxf` | чертёж DXF R2010, мм: лист 1 — схема, 2 — топология 2:1, 3 — монтаж 1:1 |
| `esp32s3-dwm3000-board-preview.png` | превью всех трёх листов |
| `esp32s3-dwm3000-board-report.md` | отчёт: расчёт, карта выводов DWM3000, BOM, проверки |
| `pins.json` | точки для проверки площадок скриптом `check_dxf.py` |
| `check_crossings.py` | проверка схемы на пересечения проводников |
| `esp32s3-dwm3000-laser.dxf` | производственный DXF под лазер: негатив, штриховка, сверловка, тест-купон |
| `esp32s3-dwm3000-laser-mask.png` | растр 1:1 (80 × 55 мм, 1200 dpi): чёрное — выжигать |
| `esp32s3-dwm3000-laser-preview.png` | превью негатива с купоном |

### Ориентация: посадки зеркальны

Плата начерчена **зеркально по вертикали** (по требованию заказчика): ряд J1 розетки — сверху,
DWM3000 с антенной — вверху справа, кипер-аут — в правом верхнем углу. Это значит, что модули
и элементы ставятся **со стороны пайки**, а медь смотрит вниз.

Если плата собирается обычным способом — медью вверх, — в генераторе ставится `MIRROR_Y = False`,
и вся геометрия (посадки, медь, шелкография, подписи) пересчитывается обратно без правок.

### Что где на плате

- **J1** — клеммник 5 В; **F1** — самовосстанавливающийся предохранитель 1,1 А.
- **U1** — AMS1117-3.3, питает только DWM3000 (0,16 А в пике, 0,27 Вт).
- **J2** — розетка 2×22 под DevKitC-1: контакт 1 слева, ряд J1 — верхний.
- **U2** — DWM3000; антенна смотрит вправо, зона x 53…73, y 0…17 мм — кипер-аут без меди.
- **J3** — гребёнка UART 1×3 (TX, RX, GND); **LED1** — индикация 5 В; **LED2** — статус на GPIO48.
- Четыре проволочные перемычки (все в BOM, показаны пунктиром на листе 2): **IRQ** и **RST** —
  обходятся веер SPI и шина 3,3 В; две **GND** — соединяют землю модуля и конденсаторов
  с основным полигоном.
- Кнопки BOOT/RESET и USB — на самом DevKit, на носителе не дублируются.

### Лазерный негатив (изготовление дома)

Лазер снимает маску там, где медь должна быть стравлена, поэтому для него нужен **негатив**:
замкнутые контуры всех участков без меди. Это отдельный производственный DXF —
`esp32s3-dwm3000-laser.dxf`, без рамок и листов, единицы мм, R2010.

| Слой | Что это | Что делать в LightBurn |
| :--- | :--- | :--- |
| `NEGATIVE` | участки без меди, замкнутые контуры (8,75 см²) | **Fill**, line interval 0,10–0,15, двунаправленно |
| `HATCH` | та же зона готовой штриховкой (шаг 0,15) | **Line** — если CAM не умеет заливку (LaserGRBL и подобные) |
| `CUT_EDGE` | контур платы | **Line**, насквозь или под резку ножом |
| `DRILLS` | центры и диаметры отверстий | не жечь, по ним сверлить |
| `MARKS` | уголки для совмещения | слабая гравировка |
| `TEST` | тест-купон 40 × 26 мм (щели 0,3/0,4/0,5/0,6) | жечь **первым**, подобрать мощность |

Порядок работы:

1. Выжечь тест-купон, посмотреть под лупой: щель чистая, соседняя медь не подпалена.
2. Этой же мощностью — плату. Если зазоры выходят уже/шире нужного, правится не файл,
   а «kerf» в LightBurn (отрицательное смещение ≈ половина ширины пятна).
3. Смыть/стереть остатки маски, стравить медь, просверлить по `DRILLS`, обрезать по `CUT_EDGE`.

Калибровка (по опыту, порядок важен):

- **Ширина пятна (kerf)** — главное число: слой `KERF` в купоне, одна линия, замерить
  ширину под лупой. `Line interval` в заливке ставить ≈ kerf / 2.
- **Фокус** — ramp-тест на обрезке: самая узкая линия и есть фокус. Если на чистую щель
  уходит 4–5 проходов, это почти всегда расфокус, а не нехватка мощности.
- **Обдув** — воздух 0,5–1 бар, сопло 2–3 мм, поток вдоль реза. Без него продукты горения
  осаживаются обратно и проходов нужно в 2–3 раза больше.
- **Скорость и мощность** — 5 проходов на 4000 мм/мин ≈ 1 проход на 800 мм/мин по энергии,
  но хуже по качеству (переосаждение, нагрев меди). Обычно лучше 1000–1500 мм/мин,
  70–100 %, 1–2 прохода.
- **Маска** — два тонких матовых слоя вместо одного толстого; тёмная краска поглощает лучше.
- **Угол сканирования** — у диодника пятно прямоугольное: 0° и 90° дают разную ширину щели,
  проверить оба.

Если после калибровки станок уверенно держит только 0,5 мм — плату надо переразвести под
этот зазор (в текущей разводке мест теснее 0,5 мм всего 8).

Три варианта подачи файла (выбрать по своему станку):

- **вектор + заливка** (рекомендую) — точные края, время по площади; нужен LightBurn или
  аналог с заливкой;
- **вектор + готовая штриховка** — слой `HATCH`, работает на любом «линейном» CAM;
- **растр 1:1** — `esp32s3-dwm3000-laser-mask.png`, 1200 dpi, ровно 80 × 55 мм, чёрное = жечь;
  для станков с режимом гравировки изображения (проверить DPI в станке).

Четвёртый путь — инверсия в CAM: взять обычный чертёж (там залита медь), в LightBurn
выделить всё вместе с прямоугольником вокруг платы и вычесть медь из прямоугольника
(Boolean → Subtract), затем залить. Работает, но легко ошибиться — файл `laser.dxf` такой
операции не требует.

### Как пересобрать

```bash
python3 -m venv .venv-pcb && ./.venv-pcb/bin/pip install ezdxf shapely pyyaml matplotlib
cd saspik-meshrover/docs/pcb
../../.venv-pcb/bin/python esp32s3-dwm3000-board.py --png
../../.venv-pcb/bin/python .dsh/skills/pcb-docs-generate/scripts/check_dxf.py \
    esp32s3-dwm3000-board.dxf --pins pins.json --clearance 0.2
```

Отчёт собирается в два шага: `make_report.py` (из скилла `pcb-docs-generate`) и дополнение
генератора `--report` (карта выводов DWM3000, расчёт питания, длины меди).

### Источники цоколёвки

- ESP32-S3-DevKitC-1 — Espressif, `ESP32-S3-DevKitC-1 User Guide v1.1` (§ Header Block) и официальный
  `DXF_ESP32-S3-DevKitC-1_V1_20210312CB.dxf`: габарит 25,4 × 62,87 мм, шаг 2,54 мм, ряды 22,86 мм.
- DWM3000 — Qorvo, `DWM3000 Data Sheet Rev B` (Table 2 — Pin Functions; § 7.2 — Module Land Pattern,
  24 контакта, 13 × 23 мм, площадки 1,6 × 1,0 мм с шагом 1,4 мм; § 6.1 — кипер-аут антенны).

### Проверки

Аудит DXF — 0 ошибок, наложений текста — 0, КЗ — 0, зазоров меньше 0,2 мм — 0,
13 контрольных точек площадок совпали с ожидаемыми цепями, пересечений проводников
на схеме — 0 (`check_crossings.py`).

Зазоры между цепями проверяет сам генератор: `esp32s3-dwm3000-board.py --check`
(дорожка-площадка, дорожка-дорожка, площадка-площадка, норма **0,3 мм**) и отдельно печатает
каждый проход дорожки между соседними контактами. Сейчас — 0 нарушений; единственный проход —
дорожка RST между контактами 7 и 8 розетки, зазор **0,47 мм** (площадки розетки уменьшены
до 1,6 мм при отверстии 1,0, чтобы зазор между контактами вырос с 0,74 до 0,94 мм).

Оговорка по земле: на одном слое полигон разрезан дорожками на 4 куска; три из них
соединяются проволочными перемычками WP3–WP5. Это осознанное решение, а не недоделка:
иного способа соединить землю под 2×22 розеткой на одном слое нет.
