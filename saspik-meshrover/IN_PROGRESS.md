### 2026-09-15 — Корректное соединение DWM3000 ↔ ESP32-S3 (WROOM)

Статус: в работе — распиновка модуля к ESP32-S3, сверка с фактическими пинами meshrover.

### 📋 Основное подключение (SPI + питание)

| DWM3000 Pin | Функция | ESP32-S3 (пример) | Примечание |
|---|---|---|---|
| VDD1 (23,24) | Питание 3.3V | 3.3V | **не подключать к 5В!** |
| VSS/GND (3,5,6…) | Земля | GND | несколько GND для надёжности |
| SPICLK (20) | SCLK | GPIO18 | |
| SPIMOSI (18) | MOSI | GPIO23 | |
| SPIMISO (19) | MISO | GPIO19 | |
| SPICSn (17) | CS | GPIO4/5 | active-low |

### ⚙️ Дополнительные пины

| DWM3000 Pin | Функция | ESP32-S3 | Рекомендация |
|---|---|---|---|
| GPIO8/IRQ (22) | прерывание | GPIO34 | опционально, но желательно |
| RST | сброс | GPIO27 | желательно для библиотек |
| WAKEUP (2) | пробуждение | любой GPIO | для deep sleep |
| EXTON (1) | выход (управление DC-DC) | — | оставить отключённым |
| GPIO6/SPIPHA (9) | режим SPI | не подключать | по умолч. Mode 0 |

### 💡 Нюансы подключения

1. **Питание строго 3.3В** — подача 5В выводит модуль из строя.
2. **SPI Mode 0** (CPOL=0, CPHA=0) — по умолчанию у DWM3000.
3. **Максимум 38 МГц**; для надёжности начинать с ~2 МГц, затем увеличивать.
4. **Подтягивающие резисторы 10 кОм** на SCK/MOSI/MISO/CS к 3.3В.
5. **Keep-out зона** вокруг встроенной антенны — без меди/дорожек/компонентов.
6. **IRQ желателен** — без него будет постоянный опрос модуля.

### ⚠️ Нюансы проекта meshrover

- В `software/include/pins.h` SPI подключён на **SPI2_HOST**: CS=GPIO10, MOSI=GPIO11, MISO=GPIO12, SCLK=GPIO13, RST=GPIO14, IRQ=GPIO15 — фактические пины **отличаются** от примера выше.
- В `config.h`: `UWB_SPI_CLOCK_HZ=20000000` (20 МГц), `UWB_SPI_HOST=SPI2_HOST`; в `lib/dw1000/dw1000.cpp` SPI уже `mode=0`.
- **Проверить:** код (`lib/dw1000`, ожидаемый `DW1000_EXPECTED_DEV_ID=0xDECA0130`) написан под чип **DW1000**, а **DWM3000** — модуль на чипе **DW3110** (device ID другой, `0xDECA0311`). При переходе с DW1000 на DWM3000 потребуется адаптация библиотеки (регистры/init-последовательность), а не только распиновка.
