# Add Task

Добавляет задачу в корневой [`TODO.md`](../../../TODO.md) — единый бэклог монорепозитория (в рабочей копии это symlink в `saspik-private`, фон не важен: работать по пути из корня).

## Когда применять

- «добавь таску», «добавь в TODO», «добавь в бэклог»;
- «добавь таску в saspik-cluster: <текст>»;
- «добавь текущую таску» — про то, что обсуждаем сейчас.

## Шаги

1. Прочитай `TODO.md` инструментом `read` и уточни структуру: `## Бэклог` с подсекциями проектов и `## Прочее`.
2. Разбери запрос:

   | Запрос | Чего не хватает | Действие |
   | :--- | :--- | :--- |
   | «добавь таску» | проект и текст | спроси оба |
   | «добавь таску в <проект>» | текст | спроси текст |
   | «добавь таску в <проект>: <текст>» | — | добавляй |
   | «добавь текущую таску» | проект | спроси проект (секции `## Текущая задача` в файле больше нет) |

3. Определи целевую секцию — `###` под `## Бэклог`:

   - `### 🤖 saspik-meshrover`
   - `### 📡 saspik-iot`
   - `### 🗄️ saspik-cluster`
   - `### 🌱 saspik-greenhouse`

4. Формат строки — `- [ ] <Текст>` без префикса проекта. Существующий текст задачи не переписывай: только добавляй новую строку.
5. Вставь строку в конец списка целевой секции через `edit`, сохранив пустые строки и оформление файла.
6. Если назван проект, которого нет среди четырёх, — создай новую `### <Имя>` в конце `## Бэклог` (без эмодзи) и добавь задачу туда.

## Что не трогать

- Задачи с `- [x]` (выполненные).
- Секцию `## Прочее`.
- `IN_PROGRESS.md` — для него есть скилл `in-progress`.

## Критерий готовности

В `TODO.md` появилась ровно одна новая строка `- [ ] …` в правильной секции; остальной файл не изменился.
