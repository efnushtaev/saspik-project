# Меню сценариев хаба

Превращает просьбу «покажи, что можно нажать» в карточку с кнопками прямо в чате: используется штатный `ask_user_question`, поэтому кнопок не нужно рисовать и ставить плагин. Клик по варианту возвращает ответ инструменту, и агент сразу выполняет выбранный сценарий.

## Как вызывать

1. Загрузи этот скилл и вызови `ask_user_question` **один раз** с заголовком «Сценарии» и вопросом «Что запустить?». Варианты — всегда этот список, в этом порядке:

   | Вариант | Что делает агент после клика |
   | :--- | :--- |
   | Итоги чатов | `session_hub_list`, затем `session_hub_digest` по каждому чату, обновлённому с прошлой сводки; в ответ — короткая сводка по каждому (3–6 строк) и одна общая мысль «что важно» |
   | Новый чат | спросить тему одним вопросом и создать чат через `session_hub_create` |
   | Промпт в чат | показать `session_hub_list`, дать выбрать чат по заголовку и отправить текст через `session_hub_prompt` |

   Именно эти три сценария — набор меню по умолчанию (выбор владельца). «Статус проектов» и «Журнал сессии» вызываются словами, без меню.

2. `multi_select` не включать: сценарий один за клик. Пустой ответ (пользователь закрыл карточку) — не переспрашивать, предложить написать сценарий словами.
3. После ответа выполняй выбранное **сразу**, без повторных уточнений, кроме случая «Новый чат» и «Промпт в чат», где нужны тема и текст.
4. Если пользователь сразу назвал сценарий словами («собери итоги», «создай чат») — меню не показывать, выполнять напрямую.

## Ограничения

- Сценарии «Итоги чатов» и «Промпт в чат» работают только с чатами того же `cwd` и только с обычными (не субагентскими) сессиями — это границы инструментов `session_hub_*`.
- Итоги не сохраняются автоматически и в журнал не дописываются: `session_log.md` больше не ведётся. Нужен след — предложи завести задачу в `TODO.md` или запись в `IN_PROGRESS.md`.
- Меню — это вопрос, а не постоянная панель: оно появляется по просьбе «меню» и живёт до клика.
