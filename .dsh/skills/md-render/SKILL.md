# md-render

Рендеринг markdown-файлов через ответное сообщение.

Когда пользователь просит показать/отрендерить `.md`:

1. Прочитай файл инструментом `read`.
2. Выведи содержимое в ответе **без номеров строк** — интерфейс отрендерит markdown.
3. Оберни блок горизонтальными линиями (`---`) сверху и снизу для визуального отделения.
4. Ничего не меняй в тексте: не сокращай, не переформатируй, не добавляй комментарии.

Если файл очень большой (больше ~400 строк) — выведи его частями, предупредив об этом, либо предложи показать конкретный раздел.
