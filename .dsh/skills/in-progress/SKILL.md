# IN_PROGRESS

Ведёт журнал хода работ: `saspik-cluster/IN_PROGRESS.md`, `saspik-iot/IN_PROGRESS.md`, `saspik-greenhouse/IN_PROGRESS.md`, `saspik-meshrover/IN_PROGRESS.md`.

## Формат файла

```markdown
Файл «хода работ» по проекту. Задачи ведутся единым списком: сверху —
незавершённые (В работе → На доработку → Нужно взять в работу), ниже —
Выполнено. Даты не пишутся.

> Незавершённых задач: N

## Ход работ

- [В работе] Тема задачи
  Статус: краткое состояние.
  - деталь / факт

- [На доработку] Тема задачи
  - что переделать

- [Нужно взять в работу] Тема задачи
  - что сделать

- [Выполнено] Тема задачи
  Статус: итог.
  - что сделано
```

Правила:

- Дат нет ни в заголовках, ни в тексте.
- Один блок = один тег + детали: строка `Статус: …` и вложенные bullets с отступом 2 пробела.
- Допустимые теги: `[В работе]`, `[На доработку]`, `[Нужно взять в работу]`, `[Выполнено]`.
- Порядок групп: `В работе` → `На доработку` → `Нужно взять в работу` → `Выполнено`. Незавершённые всегда выше выполненных.
- Счётчик `> Незавершённых задач: N` стоит после вводной строки, перед `## Ход работ`, и равен числу задач с тегом ≠ `[Выполнено]`.

## Шаги добавления

1. Уточни у пользователя: **проект** (cluster / iot / greenhouse / meshrover), **тему**, **тег** (по умолчанию `Нужно взять в работу`), **что записать** (статус и/или пункты).
2. Прочитай `<проект>/IN_PROGRESS.md`.
3. Если задача с той же темой уже есть — обнови тег и содержимое, дубль не создавай.
4. Иначе вставь блок в конец группы своего тега (перед первой задачей следующей группы).
5. Пересчитай счётчик: число строк вида `- [<тег>] …`, где тег ≠ `Выполнено`; запиши новое значение после вводной строки.

## Смена тега

1. Найди задачу по теме.
2. Замени тег и перенеси блок в конец группы нового тега, соблюдая порядок групп.
3. Пересчитай счётчик.

`[Выполнено]` — задача уходит вниз, счётчик уменьшается. Возврат из `[Выполнено]` обычно в `[На доработку]`: задача поднимается наверх, счётчик растёт.

## Проверка после правки

- у каждой задачи ровно один допустимый тег;
- группы идут в порядке `В работе` → `На доработку` → `Нужно взять в работу` → `Выполнено`;
- счётчик совпадает с фактическим числом незавершённых;
- дат в файле нет.

## Что не трогать

`TODO.md` (для него скилл `add-task`), README и docs — журнал касается только файла `IN_PROGRESS.md` выбранного проекта.
