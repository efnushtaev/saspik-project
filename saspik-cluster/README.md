# Saspik-cluster

##### ⧫ Микросервисное ядро САСПИК на NodeJS

Центральный узел платформы САСПИК, объединяющий оборудование и процессы в единую управляемую систему.
Кластер собирает данные со всех подключённых устройств, даёт пользователю единую точку управления через веб-интерфейс и связывает элементы сети (юниты и объекты) в гибкую иерархию.
Его задача — быть надёжным и независимым ядром: каждый кластер работает сам по себе, но при необходимости может взаимодействовать с другими кластерами, сохраняя целостность системы при любом масштабе.

#### Функциональные компоненты

| Компонент | Описание |
|---|---|
| [server](server/README.md) | API. ExpressJS бэкенд (микросервисная архитектура на Inversify) |
| [client](client/README.md) | UI, React SPA (CRA + TypeScript), панель управления IoT-кластером |
| [mqtt](mqtt/README.md) | Eclipse Mosquitto MQTT-брокер с аутентификацией и ACL  |
| [mqtt-rule-engine](mqtt-rule-engine/README.md) | Движок сценариев автоматизации для обработки данных и управления Объектами |
| nginx | Конфигурация обратного прокси |
| telegraf | Конфигурация Telegraf: подписка на все MQTT-топики, запись в InfluxDB |

Для хранения сценариев автоматизации, конфигураций Объектов и Юнитов используется MongoDB
