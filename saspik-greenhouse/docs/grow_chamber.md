# Камера выращивания — гидропонная установка на 2 куста

## 1. Описание

Гидропонная установка для клубники на основе канализационной трубы ПВХ ø200 мм. Метод — частичное затопление (ebb & flow). Питательный раствор подаётся сверху помпой, заполняет трубу до уровня перелива, затем самотеком сливается обратно в бак. Управление помпой через ESP32 + MQTT + rule-engine (SASPIK Cluster).

Параметры:
- Количество кустов: 2
- Субстрат: перлит
- Длина трубы: 500–600 мм
- Уровень заполнения: ~50 мм
- Расположение бака: снизу под трубой, горизонтально, из той же трубы ø200 мм
- Объём бака: ~15.7 л (500 мм длины)
## 2. Схема

[Схема установки](./Frame%2073.png)

```

                            ─── перелив (стояк 50 мм)

    подача ──────────────────┐      ┌──────┐
    от помпы                 │      │      │        ── уровень ≈ 50 мм
    ┌────────────────────────┴──────┴──────┴───────────────────┐
    │                200 мм ПВХ труба (камера)                 │
    │≈ 500 мм                                                  │
    │   ═══════════════ уровень затопления ══════════════════  │
    │                                                          │
    └─────────────────────────────────┬────────────────────────┘
                                      │
                                      ├── слив ──→ сенсорная камера ──→
                                      │                               │
    ┌──────────────────────────────────────────────────┐              │
    │    бак (200 мм труба × 500 мм)                   │◄─────────────┘
    │    ════════ уровень раствора ════════            │
    │  ┌────────────────────────────────────────┐      │
    │  │              помпа                     │─────────────────────┘
    │  └────────────────────────────────────────┘      │      подача наверх
    └──────────────────────────────────────────────────┘      (трубка 8 мм)
```

Труба расположена с небольшим уклоном (~2°) в сторону слива.

### Сенсорная камера (pH / EC)

```
                  ┌─────────────────────┐
                  │   ┌──┐       ┌──┐   │
                  │   │pH│       │EC│   │
                  │   └┬─┘       └┬─┘   │
                  │    └──────┬───┘     │
                  │           │         │
    слив ────────►│   ┌───────┴────┐    │
    из трубы      │   │  стояк     │    │
                  │   │  перелива  │    │
                  │   │  (высота   │    │
                  │   │  40 мм)    │    │
                  │   └─────┬──────┘    │
                  │         │           │
                  │   ══════╧══════     │ ← уровень остаточной жидкости (40 мм)
                  │                    │
                  │     ≈ 150 мл       │
                  └────────┬───────────┘
                           │
                           └───→ в бак
```

Сенсорная камера — герметичный пластиковый корпус (ø75 мм × 100 мм) с вертикальным стояком-переливом внутри. При каждом сливе раствора из основной трубы камера заполняется, старая порция вытесняется через стояк в бак. После завершения слива в камере остаётся ~40 мм раствора, закрывающего датчики. При следующем цикле затопления новая порция промывает камеру и заменяет раствор.

## 4. Сборка

1. **Торцы:** приклеить заглушки к обоим торцам трубы клеем для ПВХ.
2. **Слив:** в дне трубы (в нижней точке уклона) вырезать отверстие под муфту ø50 мм. Вклеить муфту с переходом на шланг слива в бак.
3. **Отверстия под стаканы:** разметить по центру верхней части трубы с шагом ~250 мм. Вырезать отверстия ø50–60 мм (по размеру стаканов).
4. **Перелив:** в торцевой заглушке (противоположной сливу) или в верхней стенке установить вертикальный стояк высотой ~50 мм от дна трубы. Через него будет уходить избыток раствора.
5. **Подача:** закрепить штуцер для трубки 8 мм сверху трубы. Трубка от помпы идёт вверх, вводится в трубу через штуцер.
6. **Уклон:** установить трубу с уклоном ~2° в сторону слива (≈ 10 мм перепад на 500 мм длины).
7. **Помпа:** поместить помпу в бак, подключить трубку подачи. Бак поставить под сливным отверстием.
8. **Стаканы:** заполнить стаканы перлитом, установить в отверстия. Стаканы должны входить плотно, но до дна трубы не доставать (≈ 10–20 мм зазора).

9. **Бак:**
    - Взять отрезок трубы ø200 мм × 500 мм.
    - Приклеить заглушки к обоим торцам.
    - Врезать штуцер 8 мм в нижней части одной из стенок — для забора раствора помпой.
    - В верхней части противоположной стенки врезать штуцер/фитинг для слива из сенсорной камеры.
    - В верхней части сделать отверстие под воздушный клапан (или просто небольшое отверстие ø3 мм для выравнивания давления).
    - Установить бак горизонтально под сливом из сенсорной камеры. Помпу разместить внутри бака или снаружи на заборном штуцере.

10. **Сенсорная камера:**
   - Приклеить заглушку к нижнему торцу трубы ø75 мм (дно камеры).
   - Установить вертикальный стояк ø8 мм в дне камеры (высота 40 мм). Стояк — трубка, выходящая через дно наружу и отводящая избыток раствора в бак. Герметизировать место прохода.
   - Врезать входной фитинг в верхней части стенки камеры (от слива из основной трубы).
   - Закрепить датчики pH и EC через герметичные вводы в боковой стенке или сверху. Чувствительные элементы должны располагаться на высоте ~20 мм от дна (чтобы всегда были в растворе после слива).
   - Соединить слив из основной трубы с входом сенсорной камеры трубкой ø8 мм. Выход стояка направить в бак.

## 5. Подключение к SASPIK

- ESP32 управляет реле помпы по MQTT-командам
- MQTT-топик: `greenhouse/grow_chamber/command`
- Формат команды: `{"state":"ON"}` / `{"state":"OFF"}`
- Цикл затопления настраивается через rule-engine в saspik-cluster (например: помпа ON на 10 мин, OFF на 50 мин)
- Датчик уровня в трубе или таймер определяет длительность цикла
